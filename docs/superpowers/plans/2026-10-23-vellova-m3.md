> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Rename and Split the chosen "command bar plus focused left column" layout with profile summaries and Reset, add the Done island with Open folder and Open file, and ship the Rename extras (all steps, Click on the PDF, from a list, sort into folders, report export, Explorer right-click) as Vellova 0.3.0.

Engine rules (the spec leaves these open; this plan fixes them):
- The name starts as `ctx.base`. A source step (`pdfValue`, `pdfPattern`, `list`) replaces the name. `value` is the last `pdfValue`/`pdfPattern` result (a `list` step never sets it); pairing and `{value}` use it.
- `pdfValue` uses `findValue` unchanged and returns its reason on failure.
- `pdfPattern`: the text is `items.map(i => i.str).join(' ')`; `invoice` is `/\b[A-Z]{1,6}[-/]?\d{3,}(?:[-/]\d+)*\b/g`, `date` is `/\b(?:\d{4}-\d{2}-\d{2}|\d{1,2}[./]\d{1,2}[./]\d{2,4})\b/g`, `custom` is `new RegExp(regex, 'g')`. The value is capture group 1 when the pattern has one, else the whole match. The `occurrence`-th match, else `no-pattern`. `title` and `created` read `pdf.title` / `pdf.created`; empty gives `no-pattern` "This PDF has no title in its document info.".
- `list`: key is the current name (`against: 'name'`) or `value` (`against: 'value'`, `not-in-list` "No value was found before this step." when null). A failed `ListRead` gives `not-in-list` with its detail.
- `replace` with `regex: true` and an invalid pattern gives `no-pattern` with the error text. `remove` `between` removes the first `start`…`end` span including the markers. `trim` trims and collapses runs of whitespace to one space. `title` upper-cases the first letter after start, space, `_` or `-`, lower-cases the rest; `sentence` upper-cases only the first letter.
- `number`: `String(start + index * step).padStart(pad, '0')`, joined with `sep` at `at`; sets `n`. Without a number step, `n = String(index + 1)`.
- `date`: `today`, `mtime` or `ctime` formatted, joined with `sep` at `at`; sets `date`. Without a date step, `date = formatDate(today, 'yyyy-MM-dd')`.
- Only PDFs reach `runSteps` (companions follow their PDF). `pdf: null` means the session did not read the text; a `pdfValue`/`pdfPattern` step then returns `{ ok: false, reason: 'internal', detail: 'The PDF text was not read.' }`.
- `NEW_STEP` defaults: number `{ start: 1, step: 1, pad: 3, at: 'end', sep: '_' }`, date `{ from: 'today', format: 'yyyy-MM-dd', at: 'start', sep: '_' }`, replace `{ find: '', with: '', regex: false, matchCase: false, all: true }`, remove `{ what: 'range', from: 1, to: 1, start: '(', end: ')' }`, case `{ to: 'upper' }`, pattern `{ preset: 'invoice', regex: '', occurrence: 1 }`, list `{ path: '', match: '', name: '', against: 'name' }`, addText `{ prefix: '', suffix: '' }`.

**Interfaces:**
- Consumes: `keywordHits`, `findValue`, `Item`; `session.picking` (Task 5).
- Produces: `proposeLabel(items: Item[], picked: number): { keyword: string; position: Position; occurrence: number } | null` (`picked` = index into `items`); `openPage(bytes: Uint8Array, page: number, canvas: HTMLCanvasElement, width: number): Promise<{ pages: number; scale: number; words: (Item & { w: number; h: number })[] }>` where `w` = text item `width` and `h` = `Math.hypot(transform[2], transform[3])`, both in PDF units.

Algorithm for `proposeLabel` (spec: "the nearest label word or words, and the position, using the same geometry the engine uses"):
```
for position of ['after', 'below', 'before', 'above']:
  candidates = items on the side the label would be on, nearest first, at most 3:
    after:  same line (|dy| <= 8), x < picked.x - 2, sorted by x descending
    before: same line, x > picked.x + 2, sorted by x ascending
    below:  same page, picked.y - y > 8, sorted by vertical distance then |dx|
    above:  same page, y - picked.y > 8, sorted the same way
  skip a candidate whose text equals the picked text or is only digits and punctuation
  for each candidate c (index ci):
    occ = keywordHits(items, c.str).indexOf(ci) + 1
    if occ > 0 and findValue(items, c.str, position, occ) is ok with value === picked.str:
      return { keyword: c.str, position, occurrence: occ }
return null
```

UI: the picker replaces the preview inside the right column (no modal): a header with the file name, page `n of m` with previous/next, `Cancel`; the rendered page (`openPage` at the column width) with one transparent `<button>` per word positioned over it (`aria-label` = the word; hover and focus show an accent outline). Clicking a word shows the proposal under the page: `Keyword` field (prefilled, editable), position segmented, match number, a live line `Gives: {value}` from `findValue`, and `Use this`. `Use this` writes the first `pdfValue` step (or makes step 1 one), clears `session.picking`, and the preview re-reads. A null proposal leaves the keyword field empty and focused, with the short status `No label found`.
