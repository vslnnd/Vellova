## Platform

web

(The UI is web-rendered inside a Tauri 2 desktop shell on Windows. The window is a desktop app, not a website.)

## Users

The author uses it every day: renaming invoices and debit notes generated by SSRS, and splitting spreadsheets to share out among colleagues. Non-technical office colleagues use it too and must manage without help, so beginner-friendliness is binding. It is also a public download on GitHub Releases. About half of runs reuse a saved profile; the other half are set up by hand for one-off jobs.

## Product Purpose

One small, fast, offline Windows app with two tools. Rename renames batches of PDFs from values found inside them, and pairs companion files. Split splits spreadsheets (.xlsx, .xls, .csv) into many files by value, by people, by rows, by parts, or by sheet. Success means the job is done right the first time, nothing is ever lost, and every batch can be undone.

## Positioning

Every run is previewed before anything is written, no operation deletes a user file, and every batch can be undone from History. It replaces two older apps, Nomina and Splitify, whose names never appear in the UI.

## Operating Context

The usual flow is to drop files, choose or tweak the rules, check the preview, and run. Typical inputs are a handful to a few hundred files per batch. Profiles hold the repeat jobs. History, Profiles, Settings and Needs attention open as panels from the title-bar island.

## Capabilities and Constraints

- Rename: value from a PDF found by keyword and position, add text, pair matching files, and rename in place or copy to a folder. Milestone 3 adds clicking a value on the PDF, patterns from the PDF, renaming from a list, modifier steps, sorting into folders, report export and an Explorer right-click.
- Split: five modes; header row Default or Manual; output name template; folder with favourites; subfolders; format; collisions; summaries; archive originals; profiles; re-run.
- Every feature that exists today must be kept.
- Known open problem (user, 2026-10-22): the left settings columns of both tools show too many options at once, have an unclear order, make the effect of a setting hard to see, and need long scrolling.

## Brand Commitments

- Ledger look: a cobalt accent, graphite dark and cool-white light themes, and Geist with Geist Mono.
- The island capsule in the title bar is loved and must be kept, along with its animations.
- No em dashes in UI text.
- The tools are named just "Rename" and "Split".

## Evidence on Hand

Synthetic test files live in `test/fixtures` (copies are in `Documents\Vellova test files`). There are no testimonials or metrics, and none may be invented.

## Product Principles

1. Show what will happen before it happens.
2. The common path is short, and rare options stay out of the way until needed.
3. Never lose a file: undo is always possible.
4. A colleague with no training gets it right.

## Accessibility & Inclusion

Full keyboard use and support for reduced motion, as already implemented.
